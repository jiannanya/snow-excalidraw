Snow-Excalidraw

AI-powered hand-drawn diagram generator · local viewer pages

Open a diagram

These pages decode a diagram bundle from the URL hash and render it locally. Run open.py to generate the URL automatically:

# open in full editor
uv run python open.py diagram.excalidraw --mode edit

# open animation player
uv run python open.py diagram.excalidraw --mode animate
✏️ Edit Viewer
Opens the full Excalidraw editor with your diagram pre-loaded. Supports export, theme switch, and drawing.
▶ Animation Player
Step-by-step animation player driven by an .animseq.json file. Play, pause, rewind, adjust speed.

Supported diagram types

Tell the AI what you need — it picks the right template automatically.

System Design Data Flow Product Journey Concept Web Org Structure Timeline View Comparison Frame Wireframe Kit Narrative Flow Sequence Diagram ER Diagram Kanban Board Sales Funnel
